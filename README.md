# BuildLab Demoblaze QA Project

## Project Overview

This project is part of the BuildLab Stage 1 Quality Assurance program. It focuses on testing the Demoblaze web application using manual testing techniques and Cypress automation.

## Application Under Test

- **Application:** [Demoblaze](https://www.demoblaze.com/)
- **Testing Approach:** Hybrid (Manual Testing and Automation)
- **Automation Framework:** Cypress
- **Programming Language:** JavaScript

## Testing Scope

The project focuses on key e-commerce functionality, including:

- Viewing product details
- Adding products to the shopping cart
- Verifying the cart total for one item
- Removing an item from the shopping cart

Manual testing also covers negative scenarios, including invalid payment details and empty contact form submissions.

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/josephtitidasola30-lgtm/BuildLab-Demoblaze-QA.git
cd BuildLab-Demoblaze-QA
```

Install dependencies:

```bash
npm install
```

### Running the Tests

Open the Cypress Test Runner:

```bash
npx cypress open
```

Run all Cypress tests in headless mode:

```bash
npx cypress run
```

The defect reports include reproduction steps, expected and actual results, severity, priority, environment details, and supporting screenshot evidence.
